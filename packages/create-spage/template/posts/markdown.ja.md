## Spage 基本構文マニュアル

### 1. イタリック体と太字

* と ** を使用してイタリック体と太字を表します。

例：

これは *イタリック体* で、これは **太字** です。

### 2. 見出しレベル

`#` を使用して見出し1（H1）を、`##` を使用して見出し2（H2）を表します。

例：

```
# これは見出し1です

## これは見出し2です

### これは見出し3です
```

### 3. リンク

`[説明](リンク先のアドレス)` を使用してテキストにリンクを追加します。

例：

これは [私のブログ](http://s-blog.suzichen.me) へのリンクです。

### 4. 番号なしリスト

`*`、`+`、`-` を使用して番号なしリストを表します。

例：

- 番号なしリスト項目 1
- 番号なしリスト項目 2
- 番号なしリスト項目 3

### 5. 番号付きリスト

数字とドットを使用して番号付きリストを表します。

例：

1. 番号付きリスト項目 1
2. 番号付きリスト項目 2
3. 番号付きリスト項目 3

### 6. 引用

`>` を使用して引用を表します。

例：

> 野火焼けども尽きず、春風吹いて又生ず。

### 7. インラインコード

\`コード` を使用してインラインコードを表します。

例：

`html` について話しましょう。

### 8. コードブロック

3つのバッククォート( \``` )を使用してコードブロックを表します。

例：
```
func:
    これはコードブロックです。
```

> 4つのインデントスペースを使用して表現することもできます。

### 9. 画像の挿入

\!\[説明](画像リンクアドレス) を使用して画像を挿入します。

例：

![AIからの印象](https://img.suzichen.me/other/blog-suzichen-me-chatGPT.png)

## Spage 高度な構文マニュアル

### 1. 取り消し線

2つの `~~` を使用して取り消し線を表します。

~~これは間違ったテキストです。~~

### 2. 脚注

`[^keyword]` を使用して脚注を表します。

これは脚注[^footnote]の例です。

これは2つ目の脚注[^footnote2]の例です。

### 3. 拡張コードブロック

41種類のプログラミング言語のシンタックスハイライトと行番号表示をサポートしています。

通常の例：

```
$ sudo apt-get install vim-gnome
```

Pythonの例：

``` python
@requires_authorization
def somefunc(param1='', param2=0):
    '''A docstring'''
    if param1 > param2: # interesting
        print('Greater')
    return (param2 - param1 + 1) or None

class SomeClass:
    pass

>>> message = '''interpreter
... prompt'''
```

JavaScriptの例：

``` javascript
/**
* nth element in the fibonacci series.
* @param n >= 0
* @return the nth element, >= 0.
*/
function fib(n) {
  var a = 1, b = 1;
  var tmp;
  while (--n >= 0) {
    tmp = a;
    a += b;
    b = tmp;
  }
  return a;
}

document.write(fib(10));
```

### 4. 表（テーブル）

```
| 項目        | 価格   |  数量  |
| --------   | -----:  | :----:  |
| コンピュータ     | \$1600 |   5     |
| スマホ        |   \$12   |   12   |
| パイプ        |    \$1    |  234  |
```
このような構文を使用して表を表します: 

| 項目        | 価格   |  数量  |
| --------   | -----:  | :----:  |
| コンピュータ     | \$1600 |   5     |
| スマホ        |   \$12   |   12   |
| パイプ        |    \$1    |  234  |

### 5. Todoリスト
